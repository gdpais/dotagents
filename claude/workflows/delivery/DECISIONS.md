# Decisions — delivery workflow

Skills produced: `delivery-lifecycle` (orchestrator, with the quality-gate, secrets-scan, release-plan and change-classifier scripts), `feature-planning`, `performance-review`, `ci-cd-pipeline`. `implementation-loop`, `appsec-review` and `release-management` were built on 2026-10-05 and removed on 2026-10-06 in favour of Anthropic skills (DL-27). Reused: `defect-first-review` (code-review workflow), `sre-incident-lifecycle`, `rca-investigation`, `incident-postmortem` (incident and RCA workflows), `coo-portfolio-review`, and the Anthropic `engineering:*` skills kept on by G-14. Request (2026-10-05): "a professional development workflow (planning, code, review, performance, security, devops, etc.) like a software company; skills and scripts where useful; a visualization."

Each stage skill also works alone. | sre-incident-lifecycle |
